# Seguridad

No publiques vulnerabilidades, secretos ni datos personales en una issue. Repórtalos mediante el canal privado **Security advisories** del repositorio de GitHub, incluyendo impacto y pasos mínimos de reproducción.

Se mantienen las versiones soportadas en `main`. Los avisos se priorizan por explotabilidad e impacto. Una excepción temporal de vulnerabilidad debe quedar documentada con responsable, justificación, mitigación y fecha de expiración; nunca se silencia globalmente un escáner.

No se ofrecen tiempos contractuales de respuesta. Este proyecto no afirma certificación de seguridad o cumplimiento legal.
