# Fixtures de proveedores

El catálogo base de FASE 9 es `data/mock/mercadona-catalog.json`. Los documentos de `scenarios` describen deltas reproducibles para pruebas de idempotencia, altas, precios, ausencias, reaparición y validación. Las pruebas E2E copian el escenario elegido a `data/providers/runtime/catalog.json`; ese directorio no se versiona.
