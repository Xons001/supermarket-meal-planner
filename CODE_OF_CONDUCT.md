# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Esperamos una colaboración respetuosa, inclusiva y centrada en argumentos técnicos. Conductas abusivas, acoso o publicación de información privada no serán toleradas. Los incidentes deben comunicarse de forma privada mediante los canales de seguridad del repositorio.
